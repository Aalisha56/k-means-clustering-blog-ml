01 / THE IDEA

What problem does it solve?

K-Means is an unsupervised learning algorithm that partitions observations into K groups. It assigns each observation to the nearest cluster centre and repeatedly updates the centres until assignments stabilise or a stopping rule is met. It is often used to explore customer segments, group products by behaviour, or summarise large collections of measurements.

In many exploratory datasets, there is no known label telling us which group each row belongs to. K-Means offers a systematic way to find compact groups based on selected numeric features—but the resulting groups are patterns in the chosen representation, not automatically meaningful customer types.

Assign xᵢ to the cluster with the nearest centroid μₖ; update μₖ as the mean of its assigned observations.

02 / METHOD

How it works, step by step

  1. 01
    Select relevant numeric features and handle missing values.
  2. 02
    Scale features when their units or ranges differ substantially.
  3. 03
    Choose K, the number of groups, using domain knowledge and diagnostics such as the elbow curve or silhouette score.
  4. 04
    Initialise K centres and assign each row to its nearest centre.
  5. 05
    Recompute each centre as the mean of its assigned rows; repeat assignment and update until convergence.

03 / VOCABULARY

Concepts worth knowing

Centroid

The mean position of observations assigned to a cluster.

Within-cluster sum of squares (inertia)

The total squared distance between observations and their assigned centroids.

K

The number of clusters requested by the analyst.

Scaling

A transformation such as standardisation that prevents large-unit features from dominating Euclidean distance.

Initialization

Starting centroids affect the solution; multiple starts help avoid poor local solutions.

Silhouette score

A diagnostic comparing how close a point is to its own cluster versus the nearest other cluster.

04 / IN PRACTICE

A realistic use case

A retailer might group stores using average basket size and monthly visits, then compare the groups’ profiles to plan inventory. The clusters do not arrive with names; the analyst studies each centroid and checks whether the grouping is stable and useful.

Questions to ask before trusting the result

  • Does the data represent the population or workflow where the model will be used?
  • Are important features missing, noisy, or measured after the outcome?
  • Would a wrong prediction have unequal costs for different groups?
  • Can the result be checked on data not used to build or tune the method?

07 / INTERPRETATION

How to interpret the output

The elbow curve plots inertia against K. Inertia always decreases as K increases, so look for a bend rather than automatically choosing the lowest value. A cluster scatter plot shows assignments in two selected dimensions; centroids summarise typical values, but overlapping clusters indicate uncertainty.

Do not confuse a pattern with proof

A plot is evidence about the rows and variables it displays. It does not by itself establish causation, guarantee performance on future data, or show that a model will remain reliable after the data distribution changes. Document assumptions and evaluate the method in the context where it will be used.

08 / TRADE-OFFS

Strengths and limitations

Where it helps

  • Simple, efficient, and easy to visualise
  • Scales to many observations
  • Centroids make cluster summaries straightforward
  • Useful as an exploratory baseline

Where to be careful

  • K must be chosen in advance
  • Sensitive to scaling, outliers, and starting centres
  • Best suited to compact, roughly spherical groups
  • Cluster labels have no intrinsic meaning and can change between runs

When should you use it?

Use K-Means when numeric features and distance-based compact groups make sense. Validate clusters with several diagnostics and domain knowledge; do not assume every dataset has a natural partition.

09 / FIELD NOTES

A practical review checklist

  • State the prediction or discovery question in plain language.
  • Document where the data came from and what each row represents.
  • Separate training, model selection, and final evaluation when fitting a model.
  • Use metrics that match the actual task and the cost of errors.
  • Compare with a simple baseline before claiming the method is useful.
  • Explain uncertainty, assumptions, and what the result cannot establish.

10 / TAKEAWAY

What to remember

Use K-Means when numeric features and distance-based compact groups make sense. Validate clusters with several diagnostics and domain knowledge; do not assume every dataset has a natural partition.

The best workflow is not simply to run an algorithm and show a graph. It is to define the question, prepare the data, explain the method, examine evidence, test limitations, and communicate what can reasonably be concluded.

11 / WORKED EXAMPLE

Worked example: naming clusters after inspecting them

Suppose one cluster has a higher mean spend and fewer visits, while another has moderate spend and frequent visits. Those summaries may suggest different engagement patterns, but names should come after inspecting the underlying values and context. A cluster ID such as 0 or 1 has no built-in meaning and can change when the model is refit.

  • Compare cluster centres in original units.
  • Check whether groups are stable across different random starts.
  • Ask whether the segmentation supports a real decision or action.

12 / REPRODUCIBLE WORKFLOW

Implementation blueprint

This optional Python example shows the usual workflow for the included CSV. It is source code for running locally, not code that runs inside this static article. Install the listed libraries first, keep the dataset file beside the script, and use the printed output as a starting point for interpretation—not as a substitute for checking assumptions.

import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

df = pd.read_csv("customer_segments_teaching_data.csv")
X = df[["annual_spend", "visits_monthly"]]
X_scaled = StandardScaler().fit_transform(X)
model = KMeans(n_clusters=3, n_init=20, random_state=7)
df["cluster"] = model.fit_predict(X_scaled)
print(df.groupby("cluster")[["annual_spend", "visits_monthly"]].mean())
print(df["cluster"].value_counts().sort_index())

How to read it: the code selects the relevant columns, applies the algorithm, and prints a summary or evaluation. Results can vary with random sampling and package versions. For a real project, document the split, parameters, metrics, and any preprocessing choices.

13 / QUALITY CHECK

Common mistakes to avoid

  • Including ID columns in distance calculations.
  • Choosing K only because inertia is lowest at that K.
  • Interpreting clusters without checking feature scales and profiles.

Before publishing a conclusion, ask whether the data supports the statement, whether the chart matches the stated method, and whether a reader could reproduce the workflow from the included files.
